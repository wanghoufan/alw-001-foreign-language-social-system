# WebView 页面状态门禁（ALW-001）

本项目 2026-11-14～16 连续 20 个版本返工，全部落在下面七类问题里。出包前逐条过一遍，不靠回忆。

## 触发场景

- 改 `socialmate-v1.2/index.html`（页面本体）或 `android-poc/**/LocalServer.java` 的静态资源路由；
- 新增任何依赖页面状态、或会触发 WebView 重载的交互（录音、`?live=1`、`reloadPage`）；
- 新增「页面内直接录音」入口（监听、按住说话、语音速记）；
- 新增「粘贴 / 导入 / 批量收录」入口；
- 外部 AI 教练 / 自动化回填类功能上线前；
- 出包并准备说「这版可以用了」之前。

## 九项检查

| # | 检查 | 判据 | 本项目的常见破法 |
|---|---|---|---|
| 1 | 列表渲染入口唯一 | 全项目搜同一容器的写入点（本项目为 `#messages`）；条数上限、排序方向、追加位置三处必须一致 | `appendBubble()` 用 `afterbegin` + 截断 3，`render()` 用正序 80 → 一会儿三条一会儿满屏 |
| 2 | 跨重载状态外置 | 内存 flag 在原生开录 / 切页后会丢；改用 sessionStorage 并带 TTL，收尾清键 | 语音捕获标记只在 `S.n08.capture` 里，重载后失效或被永久粘住 |
| 3 | 容器尺寸不被内容撑破 | flex 列向子项补 `min-width:0`；实测 `document.scrollWidth <= min(innerWidth, 请求视口宽度) + 1` | 只写 `min-height:0` 导致容器被撑到 898px、文字跑出屏幕 |
| 4 | 固定高度区域防抖 | 会随时变化的行（实时字幕、状态条）必须有固定高度，`display` 不得在 `none/block` 间切换 | 中间字幕 0/51/80px 三跳，整段对话被顶下去 |
| 5 | 外部提示词即契约 | 给外部教练/模型的提示词必须含：参考答案（标注提问前不得透露）+ 评分口径 + 带「待填」的机器可解析回填块 + 逐条硬约束 | 只给题目、只说「每题一行」→ 无法判分、回填乱写 |
| 6 | 日期本地时区 | 用 `getFullYear/getMonth/getDate` 组装；禁止 `toISOString().slice(0,10)` | 东八区 0–8 点退回前一天，`day` 与题库号对不上、同日幂等判错 |
| 7 | 产物回读 | 构建后 `unzip -p <apk> assets/v12/index.html \| grep <本轮特征串>`，并 `dumpsys package` 读已装 versionName | 改了文件却先跑构建（并行调用），装上的还是旧页面 |
| 8 | 原地录音不跳页 | 原生开录后若 `running && !live=1` 会整页重载；页面录音回调里还会 `setTab('chat')`。新增页面内录音入口必须**两处同改**：原生置内联标记跳过重载 + 页面在 capture 时不切 Tab；停止/普通入口要复位标记 | 只改页面或只改原生，点「按住说话」仍整页重载并跳回聊天页 |
| 9 | 导入结果可见 | 任何「粘贴 / 导入 / 批量收录」必须：先解析预览（逐条 / 整段 / 词组三态）→ 用户确认 → 结果置顶展开；解析为空要明确报错，不得静默跳过 | 用户粘贴后既看不到内容也不知道成功与否，误判功能坏了 |

## 强制回执（缺项不得报完成）

```text
【页面状态门禁回执】
渲染入口：<容器> 写入点 N 处，条数上限/排序一致（是/否）
跨重载状态：外置键 <key>，TTL <秒>，收尾清理（是/否）
尺寸：四宽度 scrollWidth <= min(innerWidth, 视口)（实测值）
固定区域：<区域> 固定高 <px>，0/1/2 行位移 <px>
提示词契约：答案/评分/回填块（齐/缺 X）
日期：本地时区（是/否）
原地录音：原生内联标记 <有/无>；页面 capture 不切 Tab <是/否>
导入可见：预览 <逐条/整段/词组>；保存后置顶展开 <是/否>
产物回读：APK 特征串命中 N 处，装机 versionName <x.y.z>

```

## 边界

- 只做判定与取证，不改业务代码；发现问题回到开发流程。
- 尺寸与抖动判据必须贴实测数字，不接受「看着没问题」。
- 设备相关操作仍走 `android-true-device-qa-orchestrator-local-zh` 的覆盖安装与清场流程。
