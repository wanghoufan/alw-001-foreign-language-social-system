# SocialMate V1.0 · 可交互 HTML 设计原型

## 1. 交付物与打开方式

本目录为 **可运行的、手机优先的 HTML 交互原型**，用于 ALW-001 产品审查、桌面开发者接手和浏览器操作演示。它不是已上线的 Android/ASR 正式产品。

- index.html：入口、五个一级导航、右侧内容抽屉
- styles.css：浅色默认 + 深色 + 移动 / 平板 / 桌面响应式
- app.js：搜索、筛选、详情、快速引用、模拟聊天、归档与确认、本机存储
- data.js：从正式 V1.4 软件作品集与海南资料导出的**私人工作台**离线数据
- public-share.html / public-share.js / public-places.js：独立海南只读分享原型，只含 115 地点，无私人资料
- story-seeds.json：个人话题的示例种子，用户可继续编辑
- build-data.cjs：正式源变化后，**可重复重建**私人 data.js 和公开 public-places.js
- test-prototype.cjs：无需依赖的 11 组 Node 数据、核心交互与公开数据隔离测试
- package-prototype.cjs：自动生成私有 ZIP 的脚本，不得公开
- package-public-share.cjs：只生成四文件的海南公开只读 ZIP
- SPEC.md：完整功能、交互逻辑、数据契约及正式实现方案
- TASKS.md：开发计划、验收口径及待办
- QA.md：当前检查结果、边界

## 2. 五个一级页面和对应操作

1. **软件**：软件产品 51 项；APP/PWA 优先分类、P 编号搜索、进入详情、中文概览、自然英文介绍、固定的 1/2/3/4 双语功能演示；复制英文、加入聊天参考。数据源唯一是 V1.4，未核实的功能明确提示。
2. **海南**：115 个地点；城市、分类与中英文搜索；卡片内展示城市和场景，详情内有双语介绍、高德与 Google 地图；复制英语加地图、优先使用手机系统分享面板、加入聊天参考。图片权限未验证的不纳入公共包。
3. **聊天**：演示状态有显眼标记。选择人物、开始前阅读不录音声明，手动输入朋友/自己说过的英文，按关键词自动匹配地点、作品、个人内容，同时支持手动**全库查资料**；引用已有卡片会被固定到这里；自然追问与自己的分享均可复制。结束时，核对原文、身份和对方明确提过的事实后归档。**此页不会连接麦克风或腾讯云**。
4. **关于我**：按生活/经历/兴趣等话题分类的个人卡片，每张有中文事实+自然英文，支持搜索、新增、编辑、复制、加入参考；已确认/待核实状态区分。用户的编辑只写本地浏览器，不会自动写回正式档案。
5. **人物**：虚构的 Anna 只是演示；可新建与编辑真实人物称呼、备注，查看归档会话，进入详情、选择聊天对象、导出 Markdown。若会后输入“对方明确表达”的确认事实，会关联保存到此人物的 notes；**从不自动捏造或修改真实主档**。

桌面左侧为纵向主导航，手机底部五 Tab；不在各 Tab 放重复的跨主导航卡片。详情采用抽屉；分享、复制与快速引用不用跳到无关的主页面。首屏默认浅色，墨水屏可用；右上角提供深色切换。

## 3. 三条建议自测路径

**A｜跟外国朋友演示我的软件**

进入「软件」→ 搜 P005 或 P016 → 打开卡片 → 看中英介绍 → 按编号看四步 → 复制自然英语 → 点击「引用到聊天」→ 进入聊天后看到固定参考。

**B｜分享海南地点**

「海南」→ 输入“海滩”或“骑楼” → 选城市/分类 → 打开地点 → 看中英、地图 → 点击「分享给朋友」（有 Web Share API 使用系统分享面板，否则复制英语加地图）→ 返回聊天，用「快速查资料」搜索 Wanlv / 万绿园。

**C｜模拟对话与会后归档**

「聊天」→ 选择人物 → 开始演示并确认提示 → 示例“户外活动”→ 观察匹配万绿园 → 使用/复制追问 → 点击结束并检查归档 → 人工核对原文和说话人 → 输入这次对方确认的事实（非自己的推断）→ 确认保存 →「人物」中查看人物资料和会话。所有状态仅存本浏览器。

## 5. 安全与隐私

此原型的个人卡片、人物及会话存于浏览器 localStorage；这只适合离线/个人设计审查，不是正式数据库，不保证不同手机之间同步，不保证清理浏览器缓存后保留。重要记录可导出 Markdown。不要用此原型存储不愿意泄露的真实隐私信息；原型不做身份验证和跨端加密。

正式交付需要两个独立发布面：

- **私人 Android APP + 私人服务端**：录音、实时识别、聊天建议、人物档案，连接 Mac mini 的私有存储和既有审核 API。手机登录/身份验证，TLS，访问控制，双方录音知情与停止能力。
- **公开只读 PWA/分享页**：本轮已提供公开海南 HTML 原型和四文件打包脚本。未来可单独托管 HTTPS/PWA；仅打包 115 海南地点及授权内容，不包含软件私有内容、私人会话、人物、个人故事、密钥或 localStorage。
