# V1.5 真机 UX 验收标准

设备：授权的红米 Note 12 Pro（`192.168.31.30:5555`），Android 14，App 0.8.29 / vc64。
ASR：P066 流式（`mode=p066`），预算上限 3 元/月；本轮只做短时回归，不做长 ASR。

## A. 首屏

1. 进入聊天页，第一屏能看到：对话对象、录音状态、连接方式、开始/停止按钮。
2. 第一屏**不出现**端口、模型、配对码、服务地址、诊断日志。
3. 没有新增一级 Tab；底部仍是原有 5 个入口。

## B. 字幕监看

4. 默认只显示最近 3 句，区域最大高度固定；连续说 8 句后不向下扩张。
5. 点「展开历史」能看到全部句子，区域可滚动；点「收起」恢复 3 句。
6. 用户上翻历史时，新句子不强制回顶；出现「回到最新」，点击后回顶。

## C. 建议

7. 四个方向全部出现：自然接话、继续追问、分享自己、转换话题。
8. 每个方向至少 2 个不同候选；不能只显示 1 条。
9. 英文为主；每条有中文解释且默认折叠，展开可读。
10. 每条只有朗读/复制/收藏三个图标操作，不出现整排大按钮。
11. 用户正在阅读建议时，新 final 到达不替换建议 DOM；出现「有 N 条新建议」，点击才更新。

## D. 关联资料

12. 资料条至少能显示地点、关于我、人物、软件四类中的命中项；默认是精简卡。
13. 点击卡片能打开现有详情；返回后聊天状态不丢。

## E. 状态与主题

14. 录音中显示「正在听」；停止后显示「已结束 · 可复盘」。
15. 连接方式显示家庭 WiFi / Tailscale / 本机 USB，不显示地址。
16. 浅色默认；设置切深色后聊天页可读，重启保持。
17. 主按钮触控高度 ≥48px；底部内容不被安全区遮挡。

## F. 长对话与回归

18. 注入 120 句消息：首屏仍只渲染 3 句；展开历史可滚动；页面不卡死、不白屏。
19. 120 句下建议区仍只渲染 4×2–3 张卡；滚动稳定。
20. P066 短时真机：2 条 final、`spk_0/spk_1`、归档 HTTP 201、复盘可打开，现有功能不回退。

## 判定

- 1–20 全 PASS 才算 V1.5 验收通过。
- 任何一项 FAIL 记录证据与复现步骤；不把 DOM 注入压测写成真实 ASR 长测。
- 不跑全量回归；只验本轮改动相关路径。
