# 聊天页 UX V1.5 · 规格

## 1. 布局

单栏，自上而下：

1. **顶部状态条**（固定，不随内容滚动）
   - 左：对话对象 `陈美玲`（点击切换，仅此处选人）
   - 中：录音状态 `未开始 / 正在听 / 已暂停 / 已结束`
   - 右：连接方式 `家庭 WiFi / Tailscale / 本机 USB / 未连接`
   - 主按钮：`开始录音` / `停止录音`（触控高度 ≥48px）
   - 次要：`对调说话人`（仅在有两个说话人时出现）
   - 不再放端口、模型、配对码、服务地址。

2. **字幕监看区**
   - 默认显示最近 3 句，固定最大高度（约 3 行气泡，桌面不超过 180px）。
   - 新句子从顶部进入；若用户正在阅读，不自动回顶，显示「回到最新」。
   - 「展开历史」打开一个独立滚动区，显示全部句子，最大高度 45vh；「收起」返回 3 句。
   - 未定稿字幕在列表上方，单独一行，不参与滚动。

3. **接话建议主区**
   - 四个方向，固定顺序：
     1. 自然接话
     2. 继续追问
     3. 分享自己
     4. 转换话题
   - 每个方向 2–3 个候选；英文为主，中文解释放在 `<details>` 中默认收起。
   - 候选卡操作只保留：朗读、复制、收藏（图标按钮，单行，最多 3 个）。
   - 卡片正文不得被按钮挤占；长句最多 4 行，超出可展开。

4. **关联资料**
   - 横向滚动卡条，默认精简：标签 + 标题 + 一句摘要。
   - 类型：海南地点、关于我、人物、软件作品。
   - 点击打开现有详情抽屉；不在聊天页展示搜索/手动查找（移到设置）。

5. **收尾**
   - 底部固定「结束并人工确认 / 放弃本轮」，不随建议滚动。
   - 录音结束后显示「本轮已结束 · 可复盘」。

## 2. 交互状态

| 状态 | 顶部 | 字幕 | 建议 |
| --- | --- | --- | --- |
| idle | 未开始 | 空态 | 说明文案，不生成假建议 |
| connecting | 正在连接… | 占位 | 保留上轮建议或空态 |
| ready | 正在听 · 家庭 WiFi | 实时更新最近 3 句 | 有新内容时更新，阅读中冻结 |
| error | 连接中断 | 保留最后 3 句 | 显示本地建议 + 重试入口（设置内） |
| ended | 已结束 · 可复盘 | 保留最后 3 句 | 保留建议，底部复盘按钮 |

## 3. 阅读冻结

- 用户触摸/滚动建议区或展开中文解释时，设置 `S.suggFreeze=true`。
- 新 final 到达时，只更新字幕与「有 N 条新建议」提示，不替换当前建议 DOM。
- 用户点「更新建议」后才重建；或离开建议区 8 秒后自动解冻（可配置）。
- 字幕的自动回顶同样受 `S.autoTop` 控制。

## 4. 数据

```js
S.session = {
  messages: [{who:'me'|'friend'|'unknown', speaker:'spk_0', text, time, source}],
  speakerMap: {'spk_0':'陈美玲','spk_1':'我'}
}
S.suggestions = {
  respond: [{en, zh}, ...],
  ask:     [{en, zh}, ...],
  share:   [{en, zh}, ...],
  switch:  [{en, zh}, ...]
}
S.recs = [{kind:'place'|'story'|'app'|'person', id, title, en}]
```

- 建议生成：本地模板每类至少 2 条；真实 AI 返回的 reply/share 作为第一条，模板补足第二条，禁止 `slice(0,1)` 截断。
- 关联资料：地点/软件/关于我沿用现有 `cardsFor` + 会话级实体记忆；人物来自当前 `S.person`。
- 不新增接口；继续走 `S.recs`、`planNow()`、`showRecs()`。

## 5. 视觉

- 浅色默认，深色通过 `data-theme=dark`；所有新组件用现有 CSS 变量。
- 字号：正文 ≥19px；建议英文 ≥20px；标签/辅助 ≥15px；标题 ≥23px。
- 触控：按钮 ≥44px，主按钮 ≥48px；底部留 `env(safe-area-inset-bottom)`。
- 不增加一级 Tab；设置仍走右上角齿轮。

## 6. 性能

- 字幕默认只渲染 3 条；历史展开时才渲染全部。
- 建议区按方向分组，最多 4×3=12 张卡；不一次性渲染 100 条。
- 长对话 100+ 句时，DOM 气泡只在历史展开时创建；收起后恢复 3 条。
