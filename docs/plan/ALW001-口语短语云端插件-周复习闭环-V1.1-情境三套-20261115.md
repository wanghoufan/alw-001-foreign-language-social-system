# ALW-001｜口语短语复习插件 V1.1 变更确认

日期：2026-11-15
状态：用户已确认情境造句扩展为 A/B/C 三套；需要同步更新云端插件。

## 固定题库结构
对当天照片中明确打勾的 N 个短语：
- 模式 1：中文释义 → 英文短语，N 题。
- 模式 2：英文短语 → 中文释义，N 题。
- 模式 3A：基础情境造句，N 题。
- 模式 3B：变化情境造句，N 题。
- 模式 3C：灵活应用造句，N 题。
- 总计 5N 道固定题目。模式 3 的 A/B/C 三套都必须一次生成，分别可独立复制、独立考试、独立统计。

## A/B/C 设计
- A 基础情境：最直接、简单的生活场景，建立短语与基本用法的联系。
- B 变化情境：同一短语换场景、人物或句型，避免只是 A 的同义改写。
- C 灵活应用：在另一个自然场景中主动使用，可用一到两个短句或简单前后句，但仍保持初学者友好。
- 每个短语在 A/B/C 中各出现一次；三个题干必须不同，语义场景及句子结构有实质变化。
- 每道题预先固定中文题干、完整英文参考答案、目标短语；语音教练不得自行编题或提前泄露目标短语。
- 允许自然正确的答案变体，但必须合理使用目标短语。只说短语而没有完成整句时，提醒补全。

## 每日执行
- 插件生成完整五组题库，不只生成当前选择的一套。
- 用户可把模式 3A、3B、3C 分别安排在不同日期；同一日也可独立选择任意一套。
- 语音教练启动时允许选择：1、2、3A、3B、3C、4（全部五组）。选 3 时再询问 A/B/C。
- 每套均一次一题、口头反馈、答错重答一次、中文提示后再首词提示、“不会”公布答案并跟读；记录逐题结果。

## 记录与周复习
- 试卷 set_id 绑定当天短语集合；模式 3 的 variant_id 分别为 A/B/C。
- 每次考试 session_id 独立；报告必须标明模式及 variant_id，三套成绩不得合并成一个模式 3 分数。
- 周报逐短语追踪 1、2、3A、3B、3C 五个维度，分别保留首次独立答对、提示后答对、未掌握、未作答。
- 同一短语在不同日期应使用新中文情境，不重复照搬旧题；优先复习持续薄弱项。

## 不变范围
- 不接管英语课程目录、课程进度和课程复习。
- 继续使用既有 `SocialMate-Data/Practice/Sessions/` 和 `SocialMate-Data/Practice/Reviews/Weekly/`；原始记录不可覆盖。
- 本地写入必须使用已授权 Mac 工具并回读验证；无写入工具时不得宣称已落盘。
