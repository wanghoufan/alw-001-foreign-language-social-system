## 一、分类与目标实现定义

- **LOCAL**：改写为 Android 本地实现（SQLite 表 / 私有文件 / 本地 HTTP 路由 / 原生桥），离线可用。
- **CLOUD**：改走云薄网关路由，失败只影响该按钮，不阻塞页面。
- **LAN_ONLY**：只在回家局域网由 Mac 提供，启动路径不得依赖。
- **DEMO_ISOLATED**：仅演示命名空间，真实数据同步与备份必须排除。
- **DROP**：确认无使用价值后可删除（本文件未把任何项标为 DROP，避免误删；如需删除须单独立项）。
