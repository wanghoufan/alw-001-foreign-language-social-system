## 1. 真正的目标：不是收藏夹，是主动输出学习闭环

把海南红城湖「游玩记录」拆出来的随时表达能力变成一个 **底部独立「表达」Tab**，在任何地点都能用：中文说一句或一段→利用现有腾讯 ASR/DeepSeek 生成自然英文→按固定格式留下中英词组、整理中文、唯一英文→听/循环→按需收藏其中一句→归档并关联具体海南地点；查过的术语也形成查询历史与待复习候选。

每周：课程本周已学内容 + 本周查询/翻译/收藏候选薄弱点 + 上周仍未掌握错题 → 选 5/10/15 个核心知识点 → 生成**预先固定的语音考试包** → 复制/下载交给 GPT 或豆包语音教练 → 一次一题口头答复、纠错、跟读 → **严格带题目 ID 和模式成绩回填** → 更新下周复习优先级。不要设计只供查看的「收藏夹」作为学习终点。

## 2. 三种题型：全部中文提示，英文口头作答（最高优先，不得回退）

**模式 1：中文→英文词组**。例如「叙旧、聊聊近况」，回答 `catch up`。

**模式 2：中文情境→英文完整句**。给真实情境，例如「你想约很久没见的外国朋友本周末聊聊近况」，用户自主说一条自然英文完整句；教练不得先透露词组或英文参考答案；可接受符合场景的多种自然表达。

**模式 3：中文完整句→英文完整句**。给明确中文句子，例如「我先慢跑一会儿」，用户直接说 `I start with a short jog.`；评分看意思覆盖、语法、自然度，不用机械逐词一致。

**严禁将模式 2 设成英文→中文，严禁英文到中文被动翻译题**。默认组题偏好 20% / 40% / 40%，但少量内容可各模式覆盖；不能仅看懂词组就宣布完整句子已掌握。原来已固定的 99 题老课程考试不擅自更改，这个规则只用于 N08 每周综合复习。

语音教练规约：一次一题；只用 N08 预先生成题库，不随意加题、改题、加难度；错误可重答一次；用户说「提示」，先给中文情境再必要时英文首词；用户说「不会」，立即给答案并跟读；支持「暂停」「继续」「重考错题」；参考答案只能给教练看，题目提出前不能朗读英文答案；训练完成按 `ID | 模式一结果 | 模式二结果 | 模式三结果` 回贴，每个结果只许「独立答对／提示后答对／不会」。
