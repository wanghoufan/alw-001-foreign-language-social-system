## 任务
1. **原生能力**：在 Android 侧用 `TextToSpeech`（不是浏览器 SpeechSynthesis）实现朗读桥，暴露给 WebView JS：`speakText(text, lang)`、`stop()`、`setRate(0.75|0.9|1.0)`、队列状态回调。语音选择用 `getVoices()`/`setVoice()`/`isLanguageAvailable()`，中文用 zh-CN（或 zh_CN），英文 en-US/en-GB 分别绑定**不同 voice**；绝不用 en 声线读中文。
2. **Manifest queries**：Android 11 需 `<queries>` 声明 `TTS_SERVICE` 与 `RecognitionService`，否则 `getVoices()` 返回空；按官方 API 实现，不猜。
3. **队列与生命周期**：按语言切换重建 utterance 队列；句级边界加短停顿；切段/退出页面/Activity onStop 释放队列并 `stop()`；Activity 销毁 `shutdown()`；再次使用前重新 init。
4. **播放控制**：单项朗读（中文/英A/英B/表达）、循环本段、停止、上一段/下一段；循环次数可设；倍速 0.75/0.9/1.0。
5. **失败可理解**：无中文/英文声线或语音包缺失时，返回结构化错误码（如 `TTS_LANG_UNAVAILABLE` + 缺失语言），APP 显示「去系统设置安装语音包 / 更换 TTS 引擎」提示，禁止静默无声或假成功。
6. **进度本地持久化**：每段 `已听熟` 标记与语速/循环设置本地持久化（SharedPreferences 即可），不产生任何云调用费用。
7. 版本升到 **0.8.2 / versionCode 37**；`install -r` 保留数据；`dumpsys` 回读。
