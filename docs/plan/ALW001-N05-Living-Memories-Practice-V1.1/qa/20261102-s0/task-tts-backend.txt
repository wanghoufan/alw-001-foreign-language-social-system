2. **路由**（与 8791 现有鉴权契约一致：配对短令牌 + 同源 + 写票）：

3. **缓存**：键 = `sha256(text)+recordId/blockId/revision+locale+providerId+modelVersion+voiceProfileId+rate+style`；同段重复请求必须 `cacheHit:true` 且**不产生新合成**；缓存目录在私有区（`SocialMate-Data/TtsCache/`），可清理，不与学习记录混存。
4. **适配层**：`providerId` 抽象为 adapter 注册表；实现 `fake`（默认，读本地预置音频文件，无需 Key）与 `system-fallback`（标记 FALLBACK_ONLY，不在服务端合成）；再写 `azure|elevenlabs|google` 三个 **skeleton**（接口齐全但 `enabled:false`、无 Key 时 501 `PROVIDER_NOT_CONFIGURED`，不得联网）。
5. **预算与隐私闸**：TTS 独立账本 `SocialMate-Data/TtsCache/ledger.json`，默认 `limitCny:0`，任何计费请求 fail closed 返回 402 `TTS_BUDGET_ZERO`；第三方传输默认 OFF，首次需 `explicitConsent` 并回显「将发送的文本摘录/提供商/预计费用」；不得把好友真实信息送第三方（对含 People 档案字段的请求直接拒绝）。
