# ALW-001 SocialMate 最新交接包 V1.2

这不是旧 V1.1 的简单压缩包。**V1.2 更新的是交接规范**：把经用户反馈修订的可交互 HTML 固定为界面与交互验收基准，禁止开发者自行改回手动搜索或重排主要布局。

## 先打开什么？
1. `ALW001-Interactive-V1.1.html`：离线单文件、可直接用浏览器点按。这是随包唯一 UI 验收基准，**与单独提供的 HTML 文件 SHA-256 完全一致**。
2. `DEVELOPER_PROMPT_V1.2.md`：交给 Mac mini 桌面开发者的详细完整执行提示词（必须完整阅读并执行）。
3. `UI_ACCEPTANCE_V1.2.md`：关键场景和逐项验收单。
4. `V1.4-Portfolio-Source.md`：正式软件作品集 V1.4 的原始交接副本；原项目文件仍是唯一权威数据源。
5. `screenshots/`：聊天自动推荐与地点详情的真实浏览器截图，辅助视觉对照；不可替代点击 QA。

## 核心边界
- **交互 HTML V1.1，交接规范 V1.2**，两者版本号不同是有意保留的，不是混用旧内容。
- HTML 内 51 软件/204 步是正式 V1.4；**海南只有 23 条预览样本**，正式项目必须接入完整 115 条。
- 交互中的 AI 接话是本地规则模拟，不是腾讯云 / LLM 真正返回的结果。
- 个人故事/人物数据为私人演示用途：整个 ZIP 不得直接部署到公共网站。正式公网分享仅构建可公开地点子集，剔除人物/聊天。
- 上线/正式集成前需要用户看过界面后确认；当前可直接交开发者对照实现，但**不能谎称已获得 UI 最终签收**。

## 直接启动
Mac 或 Windows 浏览器双击 `ALW001-Interactive-V1.1.html` →「聊天」→「开始演示」→「户外跑步示例」→自动看见追问和万绿园等卡片 → 点击卡片进入详细资料 → 返回聊天。

若点击 sandbox 链接无法下载，可在聊天里试 ZIP 的短英文文件名下载链接，或切换电脑浏览器下载。压缩包真实文件已通过完整性校验；浏览器是否阻止下载属于平台/UI 层面，非 ZIP 内文件损坏。
