# UI 验收清单 V1.2 — 逐项与 `ALW001-Interactive-V1.1.html` 对照

## 聊天页（最高优先级）
- [ ] 模拟或真实收到对方英语句子后，不需要搜索/点击查资料，自动出现：自然接话、2–3 个递进追问、可分享的一句话、2–4 张源资料卡。
- [ ] 「户外跑步」→ 万绿园（NO.39）/海口湾滨海步道（NO.41）/白沙门公园（NO.45），信息来源是原 115 地点库。
- [ ] 卡片点击进入正确的海南详情（不是搜索页）；中英介绍/地图/复制/分享有效；有返回聊天，保留原对话。
- [ ] 备用“手动查资料”折叠在次级位置。不要让手动搜索框占首页主视觉。
- [ ] 内容不编造用户经历或地点；模型生成追问与来源事实明确区分。

## 五个一级导航（UI 结构硬约束）
- [ ] 软件｜海南｜聊天｜关于我｜人物。手机底部固定、桌面侧栏、浅色默认、深色可切换。
- [ ] 软件：51 项正式 V1.4、204 个原编号中英演示步骤、手机 APP/PWA 优先。
- [ ] 海南：115 地点完整数据、地点 ID 可追踪、中英/地图/分享；便携 HTML 的 23 条不是产品完成数量。
- [ ] 关于我：个人双语事实与自然英语可调用，可修改，但正式主档不能被模型悄悄改写。
- [ ] 人物：原始会话→人工核实→确认入档，未确认说话人允许未知。

## 必须有实际证据
- [ ] 360/390/412/430 手机宽度，纵横屏；浅/深主题；无溢出、软键盘不遮挡主控件。
- [ ] 演示输入触发→自动推荐→点卡片→详情→返回聊天的真实浏览器点击录屏或截图。
- [ ] 测试源数据、错误/离线/无 Key 情况，安装与腾讯真实 ASR 单独标注验收状态。
- [ ] 没有改动其他开发者正在处理的 android-poc/asr-bridge 未提交代码；无擅自部署。

**严禁：只改个配色就说“符合原型”；或只做手动搜索/固定模板，而遗漏自动话题延续与动态资料关联。**
