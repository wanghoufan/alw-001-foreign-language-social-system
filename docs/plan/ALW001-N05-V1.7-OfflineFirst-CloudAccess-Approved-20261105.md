## 1. 当前确认的架构缺陷（不要误判为只需缓存头优化）
1. `AsrActivity.onCreate` 先 `showConnectingUi()`、`EndpointResolver.discoverLan(900)`，后 `showSocialMatePanel()`；主 WebView 使用 `privateUiUrl()` 远程加载 /v12。无网/远程失败仅只读 offlinePanel；旧 T4 测试不等于五 Tab 离线可写。
2. V1.6 有 /v12 no-cache + ETag + gzip 和局部地点缓存；不是完整离线安装包。表单/卡片/偏好存在浏览器 localStorage、Mac `SocialMate-Data/`、本地 SessionArchive 等多真源；需梳理后迁移。
3. Mac 上 8790/8791/8781/8782 与 Tailscale Serve 仍可保留作管理、备份和本地开发，**不得成为 APP 打开或展示资料的硬依赖**。
4. P066 的网关和腾讯 ASR 流式代理当前运行在 Mac，**不是已存在的独立云端服务**。改变 URL、继续走家里 Tailscale 不算达标。
5. V1.6 主要 CRUD、文字、图片上传已通过局部真机测试；未完项：相机拍照、原有资料覆盖层前端入口、完整备份恢复、393×852、完整聊天联动及真人 30 分钟测试。保留并进入新计划，不可谎报“已全过”。

## 2. 强制产品与架构原则
- 主界面五个 Tab 及其静态 HTML/CSS/JS 打入 APK，Android WebView 走安全本地 origin（可评估 WebViewAssetLoader + app assets，或同等安全实现；不准直接把云端页面作为首页）。冷启动不等家里 Mac、Tailscale、DNS、API。
- 本地资料库为读写真源：海南地点（既有公开原稿只读+私有覆盖层）、关于我（中英同时直显）、软件作品、人物、历史原文及媒体。用稳定 ID、版本号、删改墓碑和迁移版本；可用 SQLite/SQLiteOpenHelper + 私有文件存储或经证明可靠的同等持久层。页面、个人图片、常用音频要**真正落到手机**，不仅是临时 WebView 缓存或只读快照。
- 离线期间允许新增/编辑/搜索/软删/恢复和历史查看；本地确认后即展示。崩溃、重启、断网不丢数据。Mac 作为可选的备份/整理/同步端，不再是内容权威真源。删除本地缓存功能不得删除用户主数据。
- 中文/英文资料、收藏、图片与已缓存 TTS 音频无网络直接可看/听。新文本的自然音质 TTS 在线服务仍需网；若需要新文本无网朗读，可使用系统离线 TTS 并标注不同音色，不能用伪音频冒充豆包。
- AI 英文/翻译继续 DeepSeek，ASR 继续现有 P066/腾讯引擎能力；联网经**独立、安全、可持续访问的云端薄网关**，手机不携带任何厂商长期 Key、P066 管理 Key、项目服务端密钥；拒绝公开暴露 Mac 管理/归档端口。
- AI 文本与实时音频按原有分离同意边界发往云端；未经允许不上传私人人物档案、完整历史及照片。短期会话凭证、限速、服务端预算闸、可撤销、TLS 验证、隐私脱敏及失败明确提示是硬要求。
- 开发期间不得为了云方案改写 P066 仓库：该仓只读参考；如需改 P066 接口，先在 ALW-001 写明跨项目依赖，经对应项目单独授权再处理。

- 先查看现有 git diff、正在运行的项目开发会话，不打断同工作区其它开发者；对现有手机 App、Mac 数据、安装包、图片、原文、缓存、语音、偏好、人物、测试数据分别建立盘点及版本对照表。
- 在项目目录下完成一次**可恢复的加密/安全备份与恢复演练**：保留既有 115 地点、V1.4 软件基线、用户私有卡、媒体、人物、原文和 consent 信息；不得写 Git、不得复制到公开 PWA/公开云盘；不得把历史只读源原地改写。
- 盘点现有可用的云端托管/HTTPS 域名/DNS/部署权限、腾讯 ASR 云账号及额度、DeepSeek API、P066 接口许可、实时 WebSocket 代理能力、预算账本与存量消耗、费用和免费额度限制。严格区分：**P0 本地化不依赖新云服务，能立即开发；公网云端发布前才需真实账号授权或付费确认**。不可假定某个云平台免费、可长期承载实时 WS 或已经连通。
- 输出最少改动方案及回滚点；优先沿用 WebView UI、已通过的卡片逻辑、已有录音和预算闸。测试只需最少真实计费，不擅自增加预算。

### S1. P0 手机离线独立启动
- 将现用 0.9.1/vc69 五 Tab 页面、脚本、样式、必要图标及基础资料做确定性本地打包；签名校验、版本可见、失败回退到上一个**本地**可用版本。
- 原生启动立即显示本地界面，局域网自动发现/Tailscale 只后台尝试，不得阻塞 UI 或全屏“正在连接 Mac”。禁用由网络失败触发的主页面白屏/只读模式；离线状态仅在真正联网功能处作轻提示。
- 主页面运行逻辑不得再发起对 Mac 的首屏关键路径请求；所有缓存过期都只能影响后台更新，不影响浏览。

### S2. P0 持久化数据层与迁移
- 建立统一的本地 Repository / adapter，对齐已有 API 与 UI；将静态公开源、私有覆盖、个人故事、软件作品、人物档案及已授权历史原文做分层迁移。具体方案必须能解释 WebView→native 持久层访问、迁移失败回滚、跨版兼容与旧数据不丢。
- 图片文件、封面、用户添加图、已缓存的豆包音频保存到 APP 私有存储，按需缩略、去重、限额；不得一次性把全尺寸数据全部加载内存。备份包必须包含必要媒体。
- 继续支持中文后英文同屏直显，五 Tab 和现有紧凑布局不重做；新建/编辑/搜索/回收站/恢复真实本地读写，不仅临时 localStorage。
- 客户端需保留写入队列，待同步仍可正常编辑；不要将网络故障显示成“保存失败”。

### S3. P1 局域网手动同步、备份恢复
- 在家同 Wi-Fi 时发现 Mac，点击“同步/备份”即可上传或导入；离家无网能导出/导入本地备份文件以便迁移设备。
- 同步实现 authenticated TLS/可信局域网连接、初次配对，增量记录版本、上传确认、断点重试和幂等；冲突可人工选择版本，禁止最后写入直接覆盖用户内容。软删墓碑同样参与同步。
- 网络连接变化/手机重启/失败重试不得重复记录或覆盖。Mac 不能连时只出现小型状态，不妨碍手机使用。
- 不能以删除 Mac 原始资料作为迁移步骤；先双向核对数据数量、ID、内容 SHA、图片引用，再选择切换真源。

### S4. P1 外出 AI 翻译与实时 ASR 脱 Mac
- 独立公网云端薄网关只承担 DeepSeek 已授权文本请求和腾讯/P066 兼容实时 ASR 流式代理。设计时先验证上游协议、WS 并发、时延、供应商条款、费用/限额和长期可用性；使用现有 P066 的契约/解析成果，但运行态不得反向依赖 Mac/P066 设备。
- AI/ASR 前台采用真正短期用户/设备授权、服务端验证、撤销、限速、预算原子扣费；旧 P066/ALW 已消费额度需合并核对，不重置/重复多发预算。DeepSeek、ASR、豆包各自保持原用户批准的硬上限，绝不擅自提额。
- 原有本地录音采集/同意/停止/实时字幕/归档继续复用；可在蜂窝网络独立通过云端流式 WS 返回 partial/final，不把只支持录后 HTTP 的接口冒充实时 ASR。丢网时明确停实时识别，已确认 final/同意留存的文字本地保存并待同步；默认不保存 WAV/PCM。若要支持录音文件离线保存，另验证权限与留存同意。
- AI 失败仅影响 AI 按钮，ASR 失败仅影响本次识别，不影响资料查看编辑。弱网重试限次、超时可见、连接恢复显状态，不反复重载五 Tab。
- **云端资源没有实测可用、域名证书或授权时，不得假装已完成；先完成并验收 S1/S2/S3，可在隔离测试环境证明 S4 的安全和协议。** 需要用户本人付款/登录/创建 DNS 才提出一次性清单，不把可选正式域名当 P0 阻塞。
