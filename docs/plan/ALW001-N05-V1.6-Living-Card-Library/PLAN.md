## 产品/技术决定
- 载体继续现有Android WebView + Mac mini私有服务，三页原地增强，不更换框架/语言，不创建新APP/PWA，不引入Supabase/S3/国际服务造成额外Key。
- 模型：中文写英文使用当前已批准DeepSeek接口；语音继续现有豆包Seed-TTS2.0；ASR继续P066；未来如评估供应商须国内优先并给国外备选，但**本轮不重新选型**。
- UI 统一低噪点布局：海南图优先、关于我中英直显优先、软件图标/功能优先。唯一固定主操作「+ 新建」，其它动作按需出现，首屏实用内容最多，不使软件成为编辑器/开发看板。

## T5 关联聊天/分享

## T6 备份恢复与真机闭环

## 强制边界
- 现有 5 Tab 不增加一级导航；海南/关于我/软件作品是现有三页，**统一的是新建/搜索/分类/编辑/补充/删除/恢复/媒体/分享操作，不是把三页强制做成同样的信息排版**。不重做 V1.5.2 沉浸聊天、P066 ASR/归档、人物详情或豆包 TTS 2.0，已成功的链路仅做定点回归。
- **「关于我」列表中的中文和英文必须同时常驻直显**，不折叠、不切换语言才能看、不要求点击进入详情才能读英文。保持原中文优先、英文随后的顺序；首屏优先可快速扫视和口头交流，段落压缩为快速交流版（建议 1–2 句），完整内容仍在详情可读。不能为了省空间缩到难以阅读。
- 现有海南 115 条公开静态资料与已存 1+ 私有地点、个人档案及软件基线不得覆写/删除/改ID；采用原始数据只读 + 可写个人层/覆盖层（copy-on-write），从系统里统一检索与展示。用户手动编辑原有静态卡时形成独立的个人覆盖记录，回退可还原原始版本。新资料默认 PRIVATE。
- 仅已确认的数据参与“关于我”的对话推荐；AI英文仅是草稿，用户决定确认。不得虚构用户经历、给地点添加不存在的地图坐标、冒称软件已经上线。生成英文必须复用当前 DeepSeek 已批准私有后端及既有预算/同意闸（保持上限不变，失败时中文可单独保存）；豆包只用于 TTS，不把语音服务冒充英文写作AI。
- 手机照片必须真实持久化于本项目 `SocialMate-Data/` 的私有媒体目录，支持拍照/相册选择、移动端文件授权、压缩、旋转纠正、EXIF隐私剥离、排序/封面、删除与恢复；不以页面临时预览当上传成功。不将个人图片发布至原公开PWA/GitHub；不引入 S3/OSS/新数据库以拖延MVP。原归档若在外部系统历史目录，仅**只读盘点**、待单独安全迁移，不无授权移动/删改。
- 服务端鉴权、来源校验、资源所有权、 MIME/文件签名校验、图片尺寸及配额、ID路径穿越、原子保存、备份恢复、缩略图和缓存失效均由开发者实现或验证。无对外暴露公共编辑接口。
- 主工作树当前有未提交改动，可能有另一个开发者正在进行豆包/人物功能。**同一工作区同一时间只能一个主开发者修改；不得并发覆盖**。先用 Git diff 与工作归属确认。禁止 `git reset/clean`、无授权提交/推送/发布、加新审批 Gate、让用户反复回答已批准的需求；实施→检查→修复→复测连续推进至最终真人验收。
