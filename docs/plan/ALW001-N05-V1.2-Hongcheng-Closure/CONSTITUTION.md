# Constitution｜不可更改的产品决策与安全界限

status: USER_APPROVED
## 1. 产品交互约束（以此为最终实施目标）

### 1.1 海南 → 红城湖 → 我的记录
1. Android 的「海南介绍」地点列表增加**私有自建地点**能力（不修改原公开 115 条）：系统合并展示“115 个公共地点 + 个人地点”，红城湖私有记录用 `private:<UUID>` 或其他**独立命名空间**，绝不复用数字 1–115。
2. 红城湖详情顶部：地点封面图、地点名称/位置/简短中英背景介绍；其下是「我的游玩记录」时间线。用户 2026-11-03 实测记录应为一条可展开的 `record`，其下按练习块划分，不把 19 段原稿打散为 19 条互不关联的记录。
3. 「记录新想法」支持大段粘贴、预览字数、自动保存草稿、AI 整理、手动改分段、人工确认和再次编辑。原文、AI 修订版和用户确认版分别保留来源与版本；失败/断网退出重进不丢稿。
4. 原有地点的公开介绍始终只读；私有地点可有用户维护的“地点介绍”与个人记录。私有地点不得意外混入 PWA/公开分享。

### 1.2 点朗读就播放：授权与播放彻底拆开
- “中文 / 英 A / 英 B / 听词组 / 循环本段”是**播放操作**，不是“先弹第三方授权窗口”。已缓存音频 → 立即播放；已获相应授权且配置、预算都有效 → 先显示小型“正在生成”状态，生成后自动播放，成功后重播直接命中缓存。
- 首次 AWS Polly 接入、地区/数据外传知情同意、额度限制等放在 **设置 → 语音与隐私 → Amazon Polly** 的**一次性配置流程**。授权应有清晰范围、撤销入口，并遵守后端真实鉴权/预算闸；如必须针对特定敏感记录独立同意，在记录层进入播放页前给明确开关，而不是点每个词都弹。
- **未配置 AWS**：按钮附近显示“云朗读未就绪，去设置配置”或标禁用，绝不继续 `consent_pending → 501` 的假交互；不能悄悄切换用户已否决的系统声音。允许用户在设置里显式选“临时系统朗读”，不作为正式质量验收。
- 播放按钮变成「播放中 / 暂停 / 重播」状态并提供停止、上一段/下一段、倍速、循环。切段后旧队列彻底停、退出页释放资源。云 TTS 使用现有可插拔 adapter/音频缓存；播放 20 次最多首次合成 1 次（同文本、声线、版本等缓存键稳定时）。Amazon Polly 官方确认允许缓存重复播放无额外合成费用：<https://aws.amazon.com/polly/faqs/>。
- 正式声线：中文 `Zhiyu` Neural、美式英语 `Ruth/Joanna` Generative、英式 `Amy/Brian` Generative；实际支持地区、引擎组合由 `DescribeVoices` 探测并以真实音质实听为准。当前 AWS 预算依旧 **0 元**，选择 AWS 不等于批准付费/把真实笔记发送给第三方。

## 4. 全Task预检与安全红线

| 类别 | 必须核查 | 缺失时如何推进 |
|---|---|---|

| D 最终验收 | 已连接红米真机、真实中英文语音主观试听、手机Tailscale（外出）及第三方GPT Voice | 尽早用ADB构建安装预览；只有不可代办的真人/账号操作留最终Human Gate |

**共同约束**：只改 Android 私有 SocialMate 与 Mac 私有后端；不改公开 PWA、公开 115 个地点或任何既有真人档案；保留旧 N04/N05 已通过证据，不 reset/clean 工作树，不擅自 AWS/DeepSeek 付费、对外传输或提交真实文稿到公开 Git。
