### 1.2 点朗读就播放：授权与播放彻底拆开
- “中文 / 英 A / 英 B / 听词组 / 循环本段”是**播放操作**，不是“先弹第三方授权窗口”。已缓存音频 → 立即播放；已获相应授权且配置、预算都有效 → 先显示小型“正在生成”状态，生成后自动播放，成功后重播直接命中缓存。

- 播放按钮变成「播放中 / 暂停 / 重播」状态并提供停止、上一段/下一段、倍速、循环。切段后旧队列彻底停、退出页释放资源。云 TTS 使用现有可插拔 adapter/音频缓存；播放 20 次最多首次合成 1 次（同文本、声线、版本等缓存键稳定时）。Amazon Polly 官方确认允许缓存重复播放无额外合成费用：<https://aws.amazon.com/polly/faqs/>。

## 3. 字数上限与 AI 分段设置（明确、能测试）

**当前事实**：单条记录最多20,000 JavaScript 字符单位，红城湖 19 段Markdown 13,768单位可粘贴；但这只是单次输入接口限制，不是通用项目容量。缺少 UI 字数提示及超长草稿续传方案。

**V1.2 建议**：单次导入 UX 目标至少 **100,000 个 Unicode 字符**，输入实时显示字数/体积；客户端自动按原文位置拆为每批不超过现有服务端 20,000 上限的可恢复批次（后端需设计并验证草稿/批次/幂等/原子最终提交），所有批次完成后在**同一记录**中重组并校验原文 SHA。若手机性能/AI 成本风险大，允许先保留现有2万单批，但必须实现“继续添加下一批到同一记录”、超过时清晰提示且不丢稿；不能把一次输入截断或静默删除。不能将10万字符直接一次发 AWS Polly：官方 `SynthesizeSpeech` 每次最多3,000计费字符（6,000总字符）且输出不超过10分钟，必须按学习段合成。<https://docs.aws.amazon.com/polly/latest/dg/limits.html>

### 用户可选择的粒度
| 模式 | 建议目标 | 适用场景 |

2. 在记录里贴入整份19段实测稿 → 确认字符数 → AI 整理建议/规则降级标记 → 选择“标准”粒度 → 预览每段中英 A/B、常用表达和原话来源 → 手工合并/拆分一段 → 保存成功；查看19/19原段无遗失。
3. 点击任一有音频的“中文、英A、英B”：直接开始朗读，不弹 AWS 同意窗；点第二次暂停，再点继续，长按/点“循环本段”反复播放；切段立即停止旧段；无真实AWS配置时明确提示并阻止虚假成功。
4. 切换“精细/标准/宽松”生成不同建议；改变默认粒度不影响已保存的旧记录。单段能产生正确 GPT Voice Prompt，回贴练习结果后弱项与原段准确关联。
5. 导入超过现行20,000字接口上限的素材时，要么批量完成，要么明确可续导入并保存整篇草稿，**绝不截断后显示成功**。网络中断、人工取消、新授权缺失都不能丢源文或静默花钱。
6. 交付 Mac服务、最新APK、ADB手机安装、截图、日志和完整QA台账；需要用户操作的AWS授权/真实音质试听等集中最后一次 Human Gate。
