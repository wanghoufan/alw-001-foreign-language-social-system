## 4. 备份恢复脚本用法（S9b）

```bash
SM_BACKUP_PASSWORD='<用户口令>' node scripts/v17-backup-restore.mjs \
  --serial <目标机序列号> \
  --backup <已导出的 .smbak> \
  --port 9226
```

- 脚本自动完成：读取 counts/收藏/archive 计数 → 删除最末一条收藏 → push 备份 → `run-as` 放入 `files/import/backup.zip` → `POST /v12/api/local/import-file` → 回读并断言。
- 输出为 JSON；`verdict` 只可能是 `PASS`、`FAIL`、`BLOCKED`、`INVALID`。
- `PASS` 必须同时满足：收藏恢复且被删 id 重新出现、people/cards/records 不回退、archive `exported` 不回退、archive 总数不回退、导入返回 `imported > 0`。
- 收藏为空时脚本直接 `BLOCKED`，不得用一个空库“跑通”冒充恢复成功。
- 不实现 UI 点击，不打印口令、令牌与人物正文。
