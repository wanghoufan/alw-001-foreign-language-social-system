## 2. 架构与网络流量分工（不可倒退）

| 操作 | 唯一首选路径 | 离开 Wi-Fi 后要求 | 失败处理 |

| 首页 / 五 Tab / 已有资料与图片 | APK Assets + 手机 LocalServer + SQLite/私有文件 | 不触达 Mac；典型冷启动 ≤2 秒、Tab ≤300 毫秒作为目标 | 本地错误明确显示，不跳 Mac 远程 WebView |
| 海南地点、收藏、人物、历史、卡片 CRUD | 手机 SQLite / 已授权会话文件 | 即使 Mac 关机也能读写，重启不丢 | 写操作要事务一致，不等待同步 |
| DeepSeek 翻译/英文草稿/建议 | 手机端安全保存 Key，经原生网络调用 DeepSeek HTTPS | 真实蜂窝联网可调用、返回真实翻译 | Key/额度/服务故障只影响此按钮，保留输入文本 |
| 腾讯 ASR | 手机录音原生采集 → Tencent WebSocket `wss://`，不经过 Mac | 实时 partial/final 到界面；结束后 final 不丢 | 限次重连、进度/错误可见、停止后可重新开始 |
| 豆包朗读 | 手机端 Keystore Key → 官方 HTTPS TTS → Android/Web Audio 播放 | 新文本在线真声朗读，暂停/继续/停止有效 | 不偷偷换音色，明确告知故障和费用限制 |

### T3｜仅保留必要的本机资料、加密备份与 LAN 同步修复（P0）

- 目前 `.smbak` 只覆盖 `LocalStore.exportBackup + card_media`，缺**经用户明确同意留存**的会话原文及关联索引。补全本地归档 `SessionArchive` 中 outbox/exported（quarantine 按隐私规则单独处理），导入时保留 `sessionId` 幂等和同意状态；默认不新增 WAV/PCM 留存。

**T3 最小验收**：本机真实备份与恢复一次、1 份已获授权的会话原文及卡片媒体校验、LAN push/pull 一轮、同 ID 冲突一例、不安全 HTTP 被明确拒绝。若涉及历史隐私数据，使用经过授权的最小样本。

## 5. 开发实施纪律与风险缓释

- **工作边界**：仅 ALW-001 项目及必要的手机应用，不写 P066、000 治理仓库或其它项目；同一项目工作区只有一名开发者。任何跨项目依赖只生成说明和可复制指令，另获授权后执行。
- **依赖预检**：分“即刻开工可自办（本地代码/静态资产）／需要现有账户权限（Key/移动数据）／最终本人验收（听音/真人对话）／可选（独立云部署/正式域名）”，缺可选项不得中途停工。
- **数据安全**：保护 Mac 现有 `SocialMate-Data/`、手机 SQLite、密钥和会话文件，先安全备份；不 `git reset/clean`、不 `adb uninstall` 或 `pm clear`。变更前后记录条目计数和媒体 SHA；回滚用旧版 APK 前也要先备份本地最新内容。
- **调用授权**：音频采集、会话留存、发送 AI 云端、在线合成分别遵守现有同意边界；不在未获留存同意时备份或同步私人录音原文，不默认存 WAV。对话 transcript 不进入公开 PWA、项目 Git 或本地明文日志。
- **费用**：使用原已批准的项目预算与手机直连粗估上限，真实收费与厂商控制台核对；不能自行扩额度或做高频压测。对可能产生持续计费的 ASR 连接，确保停止/异常清理会话。
- **质量**：每发现 P0 Bug 立即定位→修复→定向复验，不因内部阶段完成就停工；无需重新进行历史 200+ 测试，但任何改动到关键路径必须补针对性自动测试。沿用项目强制 `android-overwrite-install-guard-local-zh`、`sm-card-regression-local-zh`、`webview-media-control-guard-local-zh`，按触发范围执行回执。
- **Git/交付**：没有单独授权不得自动 commit/push/生产部署，不能将调试 APK 当成公开 release。完整交付：新版 APK/版本/SHA、用户操作步骤、针对 A01–A10 的 PASS/FAIL/NOT_RUN、费用与隐私说明、遗漏事项、回滚路径；保存到项目文档后回读验证。
