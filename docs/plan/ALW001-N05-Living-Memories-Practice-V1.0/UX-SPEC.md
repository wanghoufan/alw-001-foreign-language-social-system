# N05 Android UX交互契约（原型与真实产品必须一致）

## 目前问题（已查源码）
`socialmate-v1.2/source/V1.1-baseline.html` 中`renderDemoSection`等代码将「演示人物」、演示情况及清空/恢复交互直接渲染进 People；`socialmate-prototype/ai-gateway/demo-store.mjs`本身已有独立Demo数据，**需要改视图入口，不要删除模块或QA母版**。

## 手机主导航不变
原五Tab保留：我的软件 / 海南 / 聊天 / 关于我 / 人物；右上齿轮设置是唯一的管理入口。不得新增“练习”第六Tab，不让用户被三级流程淹没。

## People 页面
- 顶部标题「我的人物」，搜索，新增；首屏主要内容为真实联系人卡片；最多一块低密度「＋ 补充朋友信息」入口（实际手动输入是真需求，而非新演示卡）。
- 点真实人物→顶部头像/基本信息/最近联系→已有五组事实/编辑撤回→「＋ 补充我知道的信息」→录入文字/语音→整理中的转圈→每条AI候选「所属组/文本/已存在冲突提醒/来源手动输入/勾选」→你确认保存→人物详情更新。
- 正式主页不得出现以下可见字符串或功能控件：「演示人物」「恢复演示数据」「清空演示数据」「回放合成final」「mock」「测试令牌」「待传测试队列」「29/39项PASS」「服务端路径」。
- 演示工具搬到 设置→高级→演示与测试（默认折叠），需要时打开，`演示模式`显式启用，可查看三人/9会话母版、清空副本与恢复、测试说明，和真实People不混。

## 海南地点与个人记录
- 正常海南卡点击后：顶部先显示`地点原档案`中英介绍；下方显著「我的记录（N次）」按时间倒序，右上「＋ 记录新想法」；这是一条地点内的纵向时间线而不是覆盖原文。
- 「录入感悟」大输入框可整篇粘贴、保留换行和中文/英语A/B、常用表达；按语义分段的预览支持合并/拆分/修改、段数、未配对提醒；顶部`AI推荐地点`最多3个候选，但必须有人工选择下拉与确认。
- 地点匹配时使用稳定`placeId`：龙兴路（id=1），不能将同义词/英文名本身当主键。原地点资料仍只读，私有数据不出现在公开PWA。
- 保存成功→地点详情显示本次记录，点入后横向按段学习而不是纵向滚动完十几段才能找到朗读控件。

## 学习与GPT练习
- 单段详情顶部段号 1/10 与进度条；中文原句→英文A/B→核心表达，可单独听与循环；只读播音时区分中文声线、英文声线，带清晰停止按钮；离开页面停止，不泄漏背景音。
- 「我听熟了·去GPT语音练习」→复制专用Prompt→切ChatGPT语音→完成练习→回SocialMate粘贴报告→AI帮助解析或人工改错→用户确认后保存→下次这段显示薄弱点和次数。
- 练习通过≠自动掌握：学习状态分未学/听读中/练习中/掌握，手动标掌握；每次复盘可追加，不覆盖旧版。
- 回贴GPT复盘必须关联固定`recordId, blockId, contentRevision`。若文章被编辑，提示练习的是旧版，防止薄弱点对应错段。

## 交互状态和错误处理
LOADING/EMPTY/OFFLINE/ERROR/UNCONFIRMED/SAVED/CONFLICT必须有明确状态；失败不弹“已成功”，原稿留在草稿。任何AI生成内容与事实更新都需确认，不凭speaker编号或AI猜测写人物正式主档。演示照片/文本必须标合成，不能当真实朋友资料。

## 视觉
优先承袭当前其它Tab的简洁浅色系统、清晰字号与密度设置；People主内容占屏70–80%，避免过高横幅；按钮集中于具体任务位置，辅助设置/测试只在设置；支持小米自带WebView、Android11 360/392/430px、中文与英文大字号、系统手势/底部Tab遮挡。

## 原型说明
本轮ChatGPT内交付 `socialmate_android_interactive_prototype.html`：手机内框可点人民补记、地点长粘贴、段落听读、复制Prompt、回贴复盘和设置；其`AI整理`、`语音录入`为显式模拟，`speechSynthesis`仅为浏览器预览而不是安卓最终实现。开发者应以本文件和正式Android当前已完成能力为依据，不拷贝原型的模拟业务逻辑进入生产。
