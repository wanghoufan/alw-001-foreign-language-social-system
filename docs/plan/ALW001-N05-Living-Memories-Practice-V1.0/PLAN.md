## P0 · MEM01 旧朋友信息：文字/语音→AI候选事实→人工确认
1. 在某个真实人物详情点「＋ 补充我知道的信息」，或在人物首页点入口后**先选目标人**。可输入/粘贴多段中文/英文；🎙按钮支持安卓录音转文本，先检查Android11可用的`SpeechRecognizer`/系统语音服务。Android12 API31才有专门`createOnDeviceSpeechRecognizer`，Android11不能假设本地离线识别一定支持；必要时用已有腾讯ASR（经用户授权/现有预算）或手动输入兜底。
2. AI解析候选事实（对象、属性、原句、来源、置信度、建议五组归类），采用既有DeepSeek私有后端，接口默认只处理**用户点击“AI整理”时**发起一次授权请求，自动去掉无关PII，令牌不进HTML。AI超时/额度不足可手工切句整理，**不使用规则假装已AI理解**。
3. UI显示原始输入逐字、每个候选附可编辑内容/分组/勾选/重复或冲突提示；用户选择、确认后才写目标人物正式主档（`People/<slug>/00-profile.md`），记录来源`manual_text`或`manual_voice`、时间、source_excerpt、输入批次ID；不得复用虚假的`sessionId/segmentIndex`。
4. 老事实不因新文本被覆盖；出现“英国/美国矛盾”“不同日期计划”时作为候选冲突由用户选追加/更正/取消；保存采用服务端ID幂等+原子写+备份/撤回。未确认草稿仅本机，用户可删除草稿；保存后立即更新人物卡片及定制话题/下一次再打开仍在。
5. 每次单人场景至少3条事实：1已存在重复、1真实新增、1矛盾；无确认0写入、错误人物0写入，保存后真实源事实不混演示。让用户随时修订删除/撤销。

## P0 · LOC01 私有地点“活档案”
1. 115地点静态原始源`socialmate-v1.2/source/places-115.json`保持不可写；新增**Android私有笔记层**，建议路径`SocialMate-Data/PlaceNotes/<placeId>/records/<recordId>.json`（主数据）及人读.md可选，私有Mac服务，只对当前APP授权设备开放。placeId使用**稳定原始ID**（例如龙兴路`id=1`）；若真实数据发生迁移，提供只读映射/冲突检测，不按地点文字直接覆盖/改ID。
2. 用户从地点详情点「＋ 追加想法」，或从首页「粘贴游玩内容」：可以一次粘贴10+段、中文+英文一种或两种表达、常用搭配。完整保留`rawInput`、来源类型`external_ai_paste`/手写/语音、创建时间与修改版本；不声称通过AI原创了用户已有的英文。
3. 本地优先按名称/地址/别名/引用编号做候选匹配，匹配不明确且用户同意时调用现有DeepSeek做语义推荐，返回top3 `placeId/confidence/reason`；**人工选择/确认才写入，AI无权自动挂错地点**。其他新地点不在115条时建议“暂存未归属”并可后补归属，不擅自新增公开地点。
4. 语义分段建议每段3–5句，但**保留原文映射和中文→英文A/B对齐**，中文一句配两种英文自然说法允许，用户可移动句子/合并拆分/编辑且数据不丢不重；常用表达为可选字段（中文释义、英文短语、搭配用法）。
5. 地点详情结构：①只读“地点原介绍”中英版；②“我的游玩记录”按时间倒序，条目可展开看上次感悟、修改历史、学习段落、练习进度；原始档案与私有笔记永不混写、公开PWA绝无个人更新。
6. 去重/写失败/版本冲突留待处理的草稿与恢复入口，不自动删除输入；10段/30-50句在 Redmi 小屏逐段可用，不要求用户滑动一个超长文本才能点朗读。

## P1 · LANG01 段落双语听读（Android原生TTS）
1. 地点记录每个studyBlock含`cn`,`englishVariants[]`(至少1,至多多个),`phrases[]`,`order`,`sourceSpan`,`learningState`,`reviews[]`。默认展示当前段，上一段/下一段和段号、中文/英语A/B/表达。
2. 点击「听中文、听英文A、听英文B、听词组」，以及「循环本段」；队列按**语言切换**（zh-CN/en-US或en-GB），句子级边界适时停顿，不把整段中文放到en-US声线，切段/返回/来电要释放队列。支持0.75/0.9/1.0倍速、循环停止、蓝牙耳机与后台策略按实际需求验证。
3. 优先Android `TextToSpeech`: `getVoices`, `setVoice`, `isLanguageAvailable`，在 Redmi Android11 实测真实英语及普通话声线/离线包/安装引导。系统中文或英文声线不可用要有可理解提示、可更换TTS引擎/语音包，不能静默无声。云端神经声线作为**后续可选选型，不是开工硬依赖**，不得无用户明确许可发送私人笔记给第三方TTS。
4. 可选「已听熟」与播放进度本地持久化；不把朗读过就等于“已掌握”。练习阶段由用户自主推进，重复听不产生DeepSeek或云TTS费用。

## P1 · PRACT01 单段 GPT Voice 练习与复盘归档
1. 每个studyBlock提供「复制 GPT 语音练习 Prompt」，生成明确包含“地点、记录ID、段ID、版本、中文段、英文A/B、目标短语”的任务；先中文逐个问常用表达并等答，再中文说整段让用户英文表达，两种自然说法都可被接受，不应提前公布英文标准答案；用语音输出简短逐轮反馈。
2. 结束要求ChatGPT输出可复制的结构化**练习复盘**（通过/需复习、掌握表达、薄弱表达、用户实际说法与改写、下次重点、段ID）；用户**自己复制**回SocialMate，系统识别/人工选择来源段，保存记录和练习次数、薄弱点、下次计划，旧报告只追加可撤销。外部GPT无法保证其语音记录100%逐字，展示“复盘由AI生成，需要本人确认”。
3. 打开ChatGPT（最好可复用同聊天文字+语音），APP只做`ClipboardManager`复制/系统分享意图；**不假设可以自动启动特定GPT Voice会话、获取ChatGPT私有语音内容/会话API，也不把GPT回答伪装成自己自动同步**。
4. 复盘可直接在段落/地点详情看到弱项；根据弱点一键重新练这段；以后扩展全局待复习列表不是本阶段必需，避免新第六Tab。
5. 两次同段练习前后不覆盖：保留两份报告的时间、通过状态与弱点变化。Prompt复制内容只用该段，不暴露其它朋友、其它地点或Mac私有API token。
