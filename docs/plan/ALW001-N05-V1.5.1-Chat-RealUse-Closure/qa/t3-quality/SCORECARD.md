# T3 接话质量评分卡（SCORECARD）

- 评测对象：`socialmate-v1.2/source/V1.1-baseline.html` 修改后的 10 话题模板
- 评测物料：`fixtures.json` + `eval-suggestions.mjs`
- 判定者：子代理 C（人工审阅抽样 + 机器指标交叉核对）
- 评分口径：每组三项各 0/1，三项全 1 才记「相关性 1」
  1. **对焦最新话题**：respond 至少 1 条直接回应最新句；ask/share/switch 至少 2 个方向带话题锚点。
  2. **自然口语**：无生硬模板拼接、无中文式英语、无“强行反问/强行邀约”。
  3. **可区分**：四方向意图不同，组内无完全重复或明显近义改写。

> `other` 的口径：不要求命中具体名词，而要求「不误判成具体话题 + 提供可靠通用接话 + 有明确转场出口」。因此机器话题对焦低不代表相关性低。

## 审阅说明

- 本次审阅是“规则模板 + 桩数据”的离线判定，不是真机语音或真实大模型输出。
- 中文解释在 10 组候选中逐条抽查：均为英文句的直译，没有加入英文里没有的地点、人物或经历。
- 编造扫描已按“断言优先于能力表达”修正：`I was born ... so I can suggest ...` 这类句子不会因为后半句有 `I can` 而被放行。
- 分享方向刻意不做身份/经历断言，只保留 `I can show / I can look up / I can share`；如后续用户补充 `profile.stories`，应另做一轮“有已确认资料”的基准，而不是解除本规则。
