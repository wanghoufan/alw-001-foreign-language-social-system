## S1｜P0 真实交流 UX 收口：不让字幕/设置吞掉用户空间
- 以 V1.5已通过的单栏布局为唯一基线，不重造页面。真机手持环境以360px、393px常用视口及正文/英文放大档分别实测首屏，观察不同字幕长度（中文/英文、短/长、异常转写），**用户不用滚整页就能触达接话区与关联卡入口**。如首屏太拥挤，只做小范围内容优先级/独立滚动/折叠优化，不靠把英文缩成13px。
- 录音开始→多次完整final→暂停阅读一条建议→继续收到新final→转到追问/分享→查看地点卡→返回→停止并复盘，过程中检查录音状态真实、光标/滚动/中文展开位置不丢、触控不误触。字幕最近3条不能因为新消息把已打开的资料卡强行收掉。
- **建议阅读冻结**：用户点选/朗读/展开中文/滚动时，新final只更新新建议数量；当前卡片不换。点“更新”才替换，用户离开阅读/恢复自动更新须有可预测、可控制的策略；不能显示隐含倒计时而突然抢屏。
- 默认隐藏调试/型号/端口/API/配对码/费用等用户不需看的技术细节；录音失败须在可见区给简洁“连接断开·重试”状态（不是沉默、也不是弹巨大诊断）。历史展开有可靠回到最新/收起，底部复盘按钮不挡内容。
- 小屏/深色/浅色/大字号/键盘与safe-area、无障碍目标≥44px、主按钮≥48px；界面必须适合真实面对面聊天时随手看。
- **禁止用DOM注入120句代替30分钟真实或受控ASR连续运行**。长录音有预算与隐私约束时，可做定时fixture驱动前端压力（明确为SYNTHETIC）+经允许最短现场真实ASR，分别出证据。

## S2｜P0 接话质量，不只看“4方向×2-3条”
- 沿用当前本地模板/BM25/可授权真实模型，不新建检索系统、不增加付费模型默认调用。对10种常见线下话题构建可复现基准：天气/海口初到/跑步健身/咖啡/海南景点/工作或软件/旅行/周末安排/音乐生活/陌生话题转场。
- 每组输入至少包含：对方最近2-3句、对话人物/上一话题（如有）、自己的已确认资料（如有）；4方向每类至少2条可区分候选。要检查是否对焦最新话题、是否自然口语、是否重复、是否凭空编造关于我/对方的经历、是否把反问硬塞给别人、是否不必要转换话题。中文解释忠实于英文，不把AI生成变成用户说过的话。
- 统一判断：相关性≥8/10组；明显语义重复/近义改写的组≤1/10；个人事实编造0；违反隐私/人物误归属0；模板未命中时明确退回可靠通用接话、可换方向，不能伪称AI语义理解。保留打分清单，至少一个人工审阅抽样。模型级真实AI表现如果没授权则NOT_RUN，不影响本地规则测量结论。
- 更新提议不可覆盖用户正在收藏/朗读的建议；同一session的会话级实体/地点记忆要继续参与卡片，当前人物卡和用户“关于我”资料需要数据来源与权限界线。
