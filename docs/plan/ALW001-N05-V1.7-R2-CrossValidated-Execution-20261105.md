## A. 审查方法与证据（代码、测试、官方三方交叉）

1. **真启动路径**：`android-poc/app/src/main/java/app/socialmate/dualmic/AsrActivity.java` 约 189–215 行显示 `showConnectingUi`→`discoverLan(900)`→`showSocialMatePanel`；约 938、1016 行最终 `loadUrl(privateUiUrl())` 指向 Mac /v12；约 965–980 行在离开 Wi-Fi 时将 LAN URL 改为 Tailscale；onReceivedError 进入只读 offlinePanel。结论：瓶颈是首屏依赖远端，不是简单 ETag 问题。
2. **局部测试不能推导完整离线**：`docs/plan/ALW001-N05-V1.6-Living-Card-Library/qa/FINAL-REPORT.md` 中 295ms 仅为联调时 WebView 加载，离线只验证单个红城湖地点的一条缓存及 19 段；不能当作 5 Tab 全离线或户外可写。V1.6 还有相机、覆盖层入口、备份恢复、完整聊天联动未跑。
3. **多数据真源**：`socialmate-v1.2/index.html` 有 `localStorage('alw-preview-v1')`、多个 `/v12/api/*`、`/api/ai/*`、`/v12/api/tts/*`、`/v12/media/*`；Mac 有 `SocialMate-Data/`、私有卡及人物，Android 自身有 `SessionArchive`。当前的 localStorage、Mac 文件和原生原文不是已整合的手机数据库。
4. **源切换会导致浏览器同源隔离**：WebView 未来从 Mac HTTPS origin 迁到 `appassets.androidplatform.net` 等 APK 本地 origin 后，旧 origin 的 localStorage/sessionStorage 与新的不共享；必须在原 origin 安全导出，原生或文件承接，完整核对后导入；不可期望更换 loadUrl 自动继承。**在清点并成功迁移前不得卸载旧包/清理数据/切断旧读取路径**。
5. **API 和桥不能仅改域名**：页面大量使用相对 URL。迁到 appassets 本地 origin 后，原先的 /v12/api、/api/ai、/v12/media 不能继续直接请求 Mac；必须逐一标注并分流到 local repository、云服务、仅 LAN 同步三类。WebViewAssetLoader 负责安全装载 APK 静态资源，**不能把它当作所有动态 POST 的现成后端**。Android 现有 `addJavascriptInterface` 暴露多个桥；更换 origin 需审查 bridge 白名单、iframe、外部跳转、XSS、令牌和异步消息，避免“保存看似成功实际落不到盘”。
6. **Android 备份设置实证**：`android-poc/app/src/main/AndroidManifest.xml` 为 `android:allowBackup="false"`；不能倚赖系统云备份完成迁移，必须完整实现“文件导出/导入 + 局域网备份恢复”。凭证不得混进可传备份包。
7. **旧证据中的外出 PASS 不是独立运行**：`docs/handoff/HANDOFF.md` 写有 Tailscale 断 Wi-Fi PASS，意味着旧版可在**Mac 在线 + Tailscale 连通**条件下工作；并非“外出永远无法用”，也不满足“Mac 关机仍能用”。正式验收要区分 VPN 远程可达与完全脱 Mac。
8. **P066 真流式已存在但预算持久性不兼容云函数**：`066-ing-ai 管理网关/server/asr/stream-relay.mjs` 确有 /api/asr/stream、x-asr-token、300s 流式代理/partial/final 预算；其 `server/asr/budget.js` 通过 fs.readFileSync/writeFileSync/renameSync 和本地锁写账本。Vercel Functions 文件系统仅提供非持久 /tmp 及只读部署文件，不能原样搬迁账本；云平台要用**可跨实例原子更新的持久预算与令牌状态**（最小状态存储，不存私人资料），不能仅用内存或最终一致缓存做金钱硬闸。
9. **云端运行时不能按旧信息定论**：Vercel 官方 2026-10-20 公告 Functions WebSocket GA；Cloudflare Workers 亦支持 WebSocket。它们是**候选**，不是已验证可承载本项目：要证明 300s 真实语音会话、上下游连续帧、出行所在地延迟、冷启动、平台/区域限制、免费额度与计费。不要引用已过时的“Vercel 不支持 WS”下结论，也不能假定免费/账号已有 SocialMate 项目。
10. **漏掉在线豆包 TTS 与动态人物功能**：`index.html` 当前 `/v12/api/tts/synthesize` + `/v12/api/tts/audio` 属 Mac 服务。若只迁 DeepSeek 和 ASR，用户在外面的“听新段落”等功能依然会坏。V1.7 外出有网完整模式必须覆盖在线豆包 TTS（沿用现有服务及预算），无网时已缓存语音可播/明示系统离线 TTS 备用；人物/收藏/会话/建议/AI 复盘等动态路由也须逐项核对，不能仅保证三大首页。
11. **隐私代码/文档存在冲突**：`AsrActivity.java` 约 478 行 `retentionConsent.setChecked(true)`，但 `docs/risks.md` 载有“默认不留存、录音与留存独立同意”。先核对现行用户确认为何以及历史逻辑；无明确独立留存同意不能默默持久化/传云。新 APK、迁移、联网 ASR、在线 AI 分开同意，且无需因为迁移重复请求非必要权限。
12. **性能/发布状态不能夸大**：Android `build.gradle` 当前 versionName 0.9.1/versionCode69，开发报表仅有 debug APK；不等于安装升级/跨设备/正式发布通过。启动2s、切换300ms均是验收目标，未实测不可标 PASS。

- 在手机仍可使用旧 origin、Mac 可达的条件下生成双重核验备份：含静态资料+私有覆盖+media+人物+已获留存授权的原文+本地草稿，排除密钥与未获授权内容；原包与新包升级路径、清空重装恢复路径各演练一次。备份数据加密/访问控制，导出操作由用户明确触发。

### C1. 本地页面与动态 API 解耦（P0）
- 优先用 WebViewAssetLoader 或同等安全 APK assets HTTP(S) origin，避免 file:// 与跨源文件权限放开。纯前端页面和必要原始资料打入 APK，原生启动不等待探测网络，读取本地数据库后可操作。
- 旧 Mac 相对接口改经统一 local repository / cloud service adapter；不能通过代理所有 /v12 请求回 Mac 来“伪离线”。保留当前 DOM、双语排版和用户操作顺序；从旧 origin 完整迁移后才切写入路径。
- 所有桥的调用约束在可信 APK 资源，拒绝外部 frame/脚本、未允许 origin 和未授权写入；最小桥能力、明确 JS/Java 异步边界，必要时使用具 origin 限制的 WebMessageListener，严格安全回归。

### C2. 设备本地存储与离线写入（P0）
- Android 私有数据库（SQLite / Room / 可靠等价物）+ 私有媒体文件；稳定 ID/版本号/数据 schema 迁移、copy-on-write 静态层、原始资料追溯与用户修改覆盖层、软删墓碑，提交事务和重启后持久性。

- 既有收藏/动态人物/本地资料写操作/历史/已确认提炼的事实，应统一到本地；旧在线特有功能按 LOCAL/CLOUD/LAN_ONLY 显示明确状态，不能出现按钮可点却请求无响应。
- 取消“Mac 不可达→整页只读面板”；真正需要外部服务时功能级提示，保留其余页面可操作。

### C3. 备份恢复 / LAN 同步（P1）
- 用户能手动导出完整私人备份包、在同/新手机导入并验 SHA/ID/照片/英文及原文数量；加密默认，备份格式及升级兼容明确，密钥与认证信息独立重建。

- 不立即删除旧 Mac 资料；核验迁移多轮一致后才将其降为备份镜像。

### C4. 外出实时 AI / ASR / TTS 的云端薄网关（P1，和本地工作可并行验证）
