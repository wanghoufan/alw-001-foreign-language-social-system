## 出题硬规则
1. 只读照片右侧明确打勾的项；英文、中文逐条核对，模糊项单独提出。
2. 每个短语三模式各一道；中文→英文、英文→中文、中文情境完整造句。
3. 第三模式中文题目短、生活化、适合初学者；标准答案预先固定，目标短语不提前透露。
4. 语音教练只照题口头发问；逐题反馈；答错一次重答；提示优先中文情境再英文首词；“不会”公布答案并跟读；不自行改题。
5. 题库末尾附标准的考试回传报告要求，务必逐题回传首次答题结果。

## 回传报告与统计
- 回传可接收纯文本 Markdown。标识 set_id、session_id、学习日期/考试日期、模式、每题目标短语、首次回答（若有）、结果、提示、标准答案、不确定项。
- 分类：首次独立答对、提示后答对、未掌握、未作答；不以提示后答对冒充已掌握。
- 不可靠的音频证据不能推断发音；不得凭用户没提供的逐题原话补造。
- 同 session_id 去重；已有记录不得静默覆盖。
- 周范围按 Asia/Shanghai 周一至周日，以考试日期归档；补考注明原学习批次。

## 技术边界
- 插件是云端指令型技能包，不内含运行在 Mac 上的服务。
- 当前会话若具备并已授权 Mac_Mini_Project_Reader 的写入工具，则可直接写 ALW-001 指定目录并回读验证；否则明确说明无法落盘，并输出待归档文件全文。
- 不开启公网服务，不部署额外服务器，不自动上传私有数据到 Git。
- 此计划文档写入不代表端到端存档验收成功。

## 首次真实验收
- 使用一张新的勾选照片：确认 N 个短语，三模式 N/N/N，无漏题/重题，题干、标准答案完整。
- 转给口语教练：验证一次一题、语音回答后口头反馈、正确/提示/不会逻辑。
- 拿到完整考试报告回粘：验证归档和回读，审查周报中的每题数据可追溯；验证重复粘贴不会覆盖或重复累计。
- 生成本周巩固包：只依据真实本地记录，优先薄弱点，固定题目与答案可直接转给语音教练。
