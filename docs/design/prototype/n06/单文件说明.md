## 一、可重复生成

```bash
cd docs/design/prototype/n06
node make-standalone.mjs   # 生成 standalone-test/standalone.html + standalone-build.json
node verify-standalone.mjs # 104 项断言 + 20 张截图，写 verify-standalone-result.json
```

- 只需 Node（脚本用 `vm` 执行现有数据文件、`fs` 读图），无第三方依赖、不联网。
- HTML 内不写构建时间；同一输入重复生成字节一致（连续两次构建 SHA-256 相同，已实测）。
- 脚本用固定锚点替换 `index.html` 的外链并改写 `app.js` 的 `photoUrl()`，锚点缺失或重复会直接报错，不会静默产出半内联文件。
- 生成后自检：不得残留 `<script src>` / `<link rel="stylesheet">`；内嵌图片数量必须与清单一致；`photoExclusions` 里的路径不得出现在内嵌映射中，命中即报错退出。
