## 2. 状态机与交互

| 状态 | 顶部主按钮 | 状态胶囊 | 麦克风 / 字幕 | 说明 |
|---|---|---|---|---|
| `IDLE` 未开始 | 开始 | 未开始 00:00 | 未开启；空态 | 点「开始」创建本轮 |
| `RECORDING` 录音中 | 暂停 | 录音中 + 递增计时 | 采集中；final 追加字幕 | 可译英、可暂停、可开 ⋯ |
| `EN_LOADING`（录音中子态） | 暂停 | 录音中 | 采集不中断 | 「译英」按钮变「翻译中」并禁用 |
| `EN_READY`（气泡子态） | 按当前录音态 | 不变 | 不新增 ASR 消息 | 英文行挂在原中文气泡内 |
| `PAUSED` 已暂停 | 继续 | 已暂停 + 计时冻结 | 麦克风已关闭；不再出新字幕 | 已确认内容可回看、可译英 |
| `FINISHED` 已结束 | 开始 | 已结束 | 本轮已封存 | 仅从 ⋯ → 结束本轮进入 |

交互细节：

1. **目标句绑定**：点任意「我」的中文气泡可选中（松绿描边）；不选时默认最后一条「我 + 含中文」的 final。译英结果回填到触发时的 `messageId`（示例 `m2`），后续朋友的英文字幕（`m3`）单独成泡，不会把译文挤到别的气泡。
2. **唯一英文版本**：译文是气泡内一行英文（18px、松绿、左侧竖线），没有复制、发送、朗读、输入框、中英模式切换等控件，也不生成第二条 ASR 消息。
3. **防重复计费**：同一句已成功后再点「译英」只提示「这句已经译好了」；请求中重复点击被忽略。
4. **无中文可译**：未开始或本轮无中文 final 时点「译英」只给「先说一句中文」轻提示，不发请求。
5. **暂停 vs 结束**：暂停只切录音状态，主按钮变「继续」，麦克风标识变琥珀色「麦克风已关闭」；「结束本轮」只在 ⋯ 菜单内，二次确认后才封存。主按钮永远不会结束本轮。
6. **同一轮多次暂停/继续**：继续时追加「已继续 · 仍是同一轮对话」分隔线与新字幕，不清空、不新建会话头；原型中可反复点暂停/继续。
7. **顶栏固定**：顶部操作栏不随字幕滚动；量测中滚动前后 `header.top` 的 top 均为 0。
8. **结束后的边界**：结束后字幕与译文保留可看，主按钮变「开始」；重新开始会清空字幕区开新一轮，不静默恢复已封存会话。

原型专用（不属于产品功能，截图时隐藏）：

- 桌面 ≥1000px 出现左上角「原型」工具条，可切深色与 375/393/430 预览宽度；
- ⋯ 菜单里的「外观」行可切主题；
- URL 参数：`?shot=idle|recording|translating|draft|paused|resumed|menu|finished`、`?theme=dark`；进入 `shot` 模式后禁用过渡动画并隐藏上述原型控件，保证截图只呈现产品界面。

主题：默认浅色，可切深色；颜色直接复用 `socialmate-v1.2/index.html` 的 `--bg/--paper/--ink/--muted/--stroke/--pine/--soft` 取值，未另造色板。

交互自测（`node docs/design/n07/n07-flow-check.mjs`，无头 Chrome 模拟点击，20/20 PASS）：

- 未开始点译英只提示、不计费，状态不变；
- 开始后进入录音中，3 条字幕出现，计时 00:00→00:01；
- 点中文气泡可选中目标（`pick` 描边）；
- 译英请求中按钮「翻译中」并禁用，结果嵌入 `m2` 原气泡，译文内无按钮；
- 译英期间计时继续（00:02→00:04）；
- 暂停后状态/麦克风/主按钮同步，计时冻结（00:04→00:04），暂停态再点译英不恢复采音；
- 继续后回到录音中，出现「已继续」分隔线与新字幕（5 条气泡 + 1 条分隔线）；
- ⋯ 可打开，结束本轮需二次确认；确认后封存、主按钮回「开始」、译英禁用；
- 结束后重新开始为新的一轮（分隔线 0、译文 0、3 条新字幕）；
- 深浅主题可来回切换；
- 全流程界面文案未出现「发送/复制/自动朗读/中文模式/英文模式」。

## 3. 三档宽度实测

量测方式：`Emulation.setDeviceMetricsOverride(width, 852, dpr=1, mobile)`，每档跑 7 个状态（idle / recording / translating / draft / paused / resumed / menu / finished），共 21 次。下表取「继续后」最密状态与「翻译中」最长按钮：

| 宽度 | 顶栏可用/内容宽 | 横向溢出 | 越界元素 | 人物下拉 | 译英 | 翻译中 | 暂停/继续 | ⋯ | 状态胶囊 | 译文行宽 | 标签底边 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| 375 | 359 / 359 | 无 | 0 | 94.3×44 | 48×44 | 63×44 | 50×44 | 44×44 | 106.7×32，未截断 | 289.0 | 844 |
| 393 | 377 / 377 | 无 | 0 | 110×44 | 48×44 | 63×44 | 50×44 | 44×44 | 106.7×32，未截断 | 305.9 | 844 |
| 430 | 414 / 414 | 无 | 0 | 116×44 | 50×44 | 65×44 | 54×44 | 44×44 | 114.7×32，未截断 | 340.7 | 844 |

结论：

- 三档 `document.scrollWidth === innerWidth`，无横向滚动、无越界元素；顶栏 `flex-wrap: nowrap` 且始终单行。
- 所有按钮高度 ≥44px，⋯ 为 44×44；375px 最挤时译英/主按钮仍为 48/50px 宽、44px 高，靠状态胶囊与人物框让位，不压小触控区。
- 375px「翻译中」最长按钮 63px，状态文字 42px 完整显示（`scrollWidth === clientWidth`，`clipped:false`），计时未被挤掉。
- 字体：字幕正文 19px，译文 18px，按钮 15px，状态/说明 14px；可见文本中小于 14px 的为 0 处。
- 顶栏固定：7 个状态 × 3 档，字幕区滚到底后 `header.top` 仍在 top=0。
- 禁用项扫描：所有状态 `app.innerText` 中未出现「发送 / 复制 / 自动朗读 / 中文模式 / 英文模式」。
- 底部标签：tags 底边 844px < 852px，未被裁切；修正过底部隐藏菜单阴影漏出造成的 8px 灰色渐变。

## 5. 未验证项与原因

1. **真实麦克风停止/恢复、真实腾讯 ASR 暂停与计费**：原型仅做 UI 状态切换，没有接真实采音；需开发实现后在 OPPO PLG110 真机验收。
2. **真实 `/api/ai/draft-en` 请求、延迟与断网失败**：原型用固定英文与本地 loading 模拟；错误回退样式已预留但未走真实链路。
3. **真实 ASR 并发回填**：用「先有 `m2`、后有朋友 `m3`」的静态顺序演示绑定关系，未跑真实识别并发。
4. **真机视觉与字重**：未在 OPPO ColorOS 实机、系统字体缩放、横屏、520px 下核对；本任务只要求 375/393/430。
5. **深色主题**：仅截了 `draft` 一态，其余状态只按同一套 CSS 变量推导，未逐态截图。
6. **⋯ 菜单中「对调说话人」「诊断与设置」**：原型只给轻提示，不是真实功能；N07 批准范围只要求保留入口。
7. **手势与滚动细节**：字幕长列表滚动、底部菜单拖拽、长按选择未做自动化验证。
8. **对比度未量化**：沿用产品现有色值，未跑 WCAG 对比度计算。
