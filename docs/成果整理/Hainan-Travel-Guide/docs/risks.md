# 风险

1. **地点归属未逐张人工核验**：当前依赖 Commons 标题/描述/分类 + 地区黑名单，仍可能有同名或邻近地点误配。
2. **照片覆盖不足**：153/345；59 处无合规图，直接影响“每处 3 张”的承诺。
3. **网络依赖代理**：Wikimedia 需 127.0.0.1:7897；代理不可用时发现/下载全断。
4. **Openverse 不稳定**：首请求常 30–50s，匿名限流；不要作为主链路。
5. **店铺/营地/游船时效性**：V2.0 文案未重新实地核验，可能已变更或停业。
6. **大文件入库风险**：45MB ZIP 在项目 Git 内，误提交会显著增大仓库。
7. **HTML 图片路径依赖 `images/` 目录**：单独拷 HTML 会缺图，必须整包分发。
