## 4. 345张真实照片的获取与核验方法（核心工作）

**每处3张尽量呈现三个不同内容**：A 整体环境/地标；B 这个地点真正独特的细节（例如龙兴路的咖啡外摆、街拍门头）；C 实际游玩或不同视角（例如黄昏街景、人流、冲浪），避免三张重复构图。首要目标是**真实且拍对地方**，不是随便配三张漂亮图。

按此顺序找来源并自动留痕：

1. **优先可合法再分发的实景图**：Wikimedia Commons（逐张检查授权、作者、署名、是否限制衍生）、有明确授权的政府/景区公开图库或景区直接授权图、其他授权明确且允许所需用途的图库。图库可能只有泛海南照片，必须证明照片属于具体地点。
2. **官方图文、主流媒体、实地报道、地图和用户游记**：用于核验地点外观与具体场景；若无再分发许可，不能仅因为公开可看就复制进 ZIP。可保留“供核验的来源链接”并另找授权素材。
3. **小众场所/独立店铺**：精确到中文店名、道路、地标、店家主页和日期，不准用邻近街道或同名其他城市的照片代替。如龙兴路/滨海新村/侨中里要区分街区、咖啡馆和店铺；店铺可能更替，需核实仍存在。
4. **缺口处理**：交叉搜索中文全名、区县+地标、英文名称/拼音、别称；无法确认版权或地点，则留空、列 `MISSING_OR_BLOCKED.csv`，不得调用生成式图片冒充真实照片。

核验至少覆盖：地点与照片匹配（不同城市同名排除）、新闻/摄影时间是否过时、截图/水印/广告/拼图排除、真实图片 URL 和来源页是否一致、许可条件是否允许打包、内容是否体现独特特色。对可疑项优先打开来源网页核对图片上下文，用视觉比对地标/建筑/店招；不能只凭文件名或搜索结果标题判断。对“街区已改造、商家搬迁、灯塔配色、潮汐海岸、活动临时开放”等动态信息追加日期和警告。

技术校验：真实 HTTP 200、`Content-Type` 为支持的图片、Pillow 可以解码、尺寸建议长边≥1000px（小众稀缺资源可保留较小图并标注）、文件非0字节、EXIF方向正确；SHA-256 做精确去重、感知哈希做近似去重；同一张照片不得跨不同地点重复使用。下载并发保守控制（例如全局3—5、单站1—2），按站点规则退避；网络异常重试后记录缺口，不能无限循环。优化后生成适合 HTML 的 JPEG/WebP，原作者署名及来源仍保留。正式打包分发图片前，逐张满足相应许可及署名要求。

## 5. 115处地址与文案统一整改要求

这项整改已在 V2.0 做过一轮，但仍需要**再次严格复核**：

- 每条开头先说明**在哪个城市/区县、哪条路或哪个地标附近**，外国人一看就知道怎么找；如果没有精确门牌，明确写“某镇/片区、某地标附近”，不要编造门牌、导航坐标。
- 第二部分写**这地方与其他地方不同的亮点**。例如龙兴路不应只说“有咖啡馆适合拍照”，要明确是国贸片区近期很火的街拍地，很多博主和年轻人来拍照，店铺门头、绿植、露天座位、巷子氛围容易出片；其他115处也应各自抓住真实特别之处。
- 第三部分说**怎么体验**：什么时间来、能拍什么/吃什么/玩什么、适合哪些人。不得为每个地点重复“风景漂亮、适合散步拍照”。
- 先中文再英文。中文用朋友聊天式大白话，每条约90—150字（优先内容充实、不硬凑）；英文约55—90词，**简单自然**，不逐字硬译，准确包含定位、亮点、玩法；长度以信息充分、不冗余为准。用户已经认可较丰满的“龙兴路”样例，**不要退回早期过短的50字介绍**。
- 不能添加或恢复故居、祠堂、陵墓、纪念馆、纯革命旧址；继续保留115处候选，不因某地点缺图擅自删除。若某地点不存在/重复/停业，记录证据，提出等量替换候选并在变更日志标明。
- 更正不自然英文（例如 `You can find it at The...` 之类错误），统一英文地名、大小写、冠词及自然表达。对“最近很火”“新晋网红”等时效性表达标清年份，过时须调整。
- 高德与 Google Maps 使用**具体地点查询词**，随机抽样甚至逐条核查跳转后是否确实找到对应位置；不能把拼音相似的别处误当目标。用户可在中文模式或仅英文模式中快速复制名称/位置。

>
> **English**: Longxing Road is near the Guomao area in Longhua District, Haikou. It's become a really popular spot for street photography, especially among influencers and young people. With stylish cafés, beautiful storefronts, and lots of photogenic corners, it's pretty easy to get great pictures here. Late afternoon is a nice time to visit.

## 6. HTML与图片 ZIP 的最终设计

必须**继承已有 V2.0 页面结构**，不是从零做个粗糙新网站。默认浅色、支持深色、适合墨水屏；PC和手机都可读。左侧地点名，右侧中文、英文介绍（手机上自适应纵排）；每处展示3张实际图片、点击放大、图注和来源/署名；用“海口/文昌/琼海/万宁/陵水/三亚/其他”“网红街拍/海边/夜市/户外”等筛选、关键词搜索、可切中文/双语、明显的高德和Google导航入口。优先体现照片和内容，避免重复导航、冗长说明、装饰性卡片和无意义跳转。

离线 HTML `src` 指向相对路径 `images/{city_folder}/{id}/01.webp` 等；根据真实生成格式同步写回 JSON 与清单，禁止 `.jpg` 路径指向实际 WebP，禁止 `file://` 的跨域 `fetch()` 导致 JSON 加载失败。可将必要数据内嵌在 HTML 中以保证双击离线可用；不要依赖外部 JS/CSS/CDN/在线字体/地图来显示主内容，外部地图只在点击导航时联网。没有通过核验的照片显示明确“待补图”，不自动加载不确定的外链代替。

图片图注应写得具体，例如“龙兴路街边咖啡馆外摆”“文昌石头公园海边巨石”“日月湾冲浪区”，并在独立来源页或 Manifest 展示作者、来源与授权。对安全风险（野海滩、临海礁石、潮汐、野生动物、航空发射区域）用简短提示，不作虚假的“都能游泳/随时开放”保证。
