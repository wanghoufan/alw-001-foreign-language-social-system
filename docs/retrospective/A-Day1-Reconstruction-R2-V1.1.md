## 2 我方 V1.0 的方法论复盘（不是自我批评，是可复用的检查点）

1. **行号引用必须可重跑**：S1、S4 两处都是「结论对、位置错」。教训是引证前重跑一次 `sed -n`，不凭记忆写行号。
2. **同名文件必须先定性再判漂移**：S2 差点把准确文档判成失真。检查点：判「文档与代码不一致」前，先 `grep -rl` 确认被引符号落在哪个文件。
3. **计数类结论一律给命令**：我方 94、14,474、52 均可复现；B 的 53、11 因无命令而偏差。V1.1 起凡数字均附命令（§8）。
4. **「落地」与「覆盖」要分档**：L14 的 7/7 是「条目都有对应实现」，但缺「利益相关方是否覆盖」。检查点：隐私类需求按「本人 / 对方 / 第三方平台」三侧分别核对。
