# 阶段复盘 · 2026-11-02（N03b 产品化收口 + N04 演示闭环）

## 发生了什么
一天内从 0.5.3 推到 0.7.3（28），主线是三件事：把「开发态界面」改成产品态、把界面变双语、把三个人物演示做成可检查的闭环。

## 做对的
1. **先证根因再改**：返回键白屏不是样式问题，是 `onBackPressed` 把整个 `webPanel` 设成 `GONE`；改完用「开详情→按返回」复现路径验证，而不是看截图猜。
2. **量化代替感觉**：字号下限、Tab 高度、空态高度、图片加载数都用 CDP 量出来（如空态 175px→55px、Tab 69→57px、最小字号 9px→13px）。
3. **并行子代理 + 文件域隔离**：图片补全、历史页英文化、演示数据、待确认事实四路并行，各自只改自己那棵树，冲突可控。

## 做错的
1. **同一天的界面反复返工**：顶栏先加三个按钮、再瘦成 `⋮`、再整条删掉——三次都因为没先问「这条控件给谁用」。
2. **字符串模板里塞 `${}` 进单引号**，一天踩两次语法错；已写进 `agent.md`。
3. **字段链路断在构建层**：`photo_note` 写进 `data/places.json`，但前端读 `source/places-115.json`，白改一轮。
4. **把「找不到干净图」当成「没图」**：实际是检索策略单一，换 Bing 直连后 52/58 补齐。

## 下次怎么做
- 新增数据字段：先追「谁读它、从哪读、构建有没有映射」三问，再动手。
- 界面元素先过一遍「这是给用户还是给我调试」清单，避免装了拆。
- 演示/示例数据一律进独立命名空间 + 显式标识，默认可见也不许污染真实档案。
